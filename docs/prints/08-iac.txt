- **Porta admin nunca aberta para `0.0.0.0/0`:** no `network.tf`, o SSH usa

- **Nuvem criada por Terraform:** provisão da VPS AIS via OpenStack.

Para rodar:

```bash
cd terraform
terraform init -backend-config=backend.hcl
terraform plan -var-file=terraform.tfvars
terraform apply -var-file=terraform.tfvars
```

> Para o print em PNG (`08-iac.png`): rode `terraform apply` e capture o resumo
> (`Apply complete! Resources: N added`) mostrando a instância e o security group,
> com o `admin_ssh_cidr` setado para um IP específico.
