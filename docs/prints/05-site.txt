# Situação do /stub_status (importante)

O endpoint `http://4.168.236.152/stub_status` **ainda retorna o HTML do site**
(não as métricas de conexões do Nginx). Isso significa que **a imagem atualmente
publicada na VPS é a anterior**, sem o `nginx.conf` atualizado com o bloco
`location = /stub_status`.

Para o Prometheus coletar as métricas, é necessário **redeployar o código novo** na VPS
(`docker compose up -d --build web`). O `nginx.conf` deste repositório já prepara o
endpoint; só falta subir a imagem nova.
